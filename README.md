# Stremio ARM64 for Orange Pi 5 Pro / Ubuntu 26.04

Reproducible packaging project for an unofficial native ARM64 build of Stremio 4.4.181 targeting Orange Pi 5 Pro systems running Armbian with Ubuntu 26.04 (Resolute Raccoon).

The project uses the official `Stremio/stremio-shell` source at a pinned commit and carries only the compatibility and Debian-packaging changes needed for this target. See `upstream.env` for all pinned upstream inputs.
